Desktop, built for desktop

This covers all 33 states from the phone app, side by side at 1440 × 900, plus a 1024 px compact layout. The phone designs (Haven Site v2) are unchanged. Desktop reuses the same buttons, rows, orb, skies and words; only the layout changes. Phone popups become desktop panels: Style, Transcript, Get help, sky picker, pattern topic, and the menu, which becomes an account menu in the sidebar. Only decisions remain as dialogs: consent, End and Delete. Calmer pass: Home and Breathe now have no right panel, so there is just the orb, one question and one text box. Recent is trimmed to 4. Shortcut hints, badges, the status pill and "Noticing so far" are removed, and Get help appears once, in the sidebar. The previous version is kept as Haven Desktop v1.dc.html. The component is Haven Desktop.dc.html, with the props screen and compact.
