# Haven v2: every screen, sheet and state (Deep lagoon)

The source for every frame is `Haven App v2.dc.html`, with the props `screen` and `desktop`. The canvas that shows them all is `Haven Site v2.dc.html`. The old version of each screen comes from `Haven App.dc.html` (round 1) or `Haven R2.dc.html` (round 2).

## Screens
1. **Home, first visit:** orb, what Haven is, Talk + Write, Help me slow down, the three promises, disclaimer
2. **Consent sheet:** AI not clinician, not for emergencies, remember switch, privacy line, 18+ check, Let's begin (disabled until checked), Not now
3. **Home, returning:** greeting + sky line, the question, Pick up from last time, starters, dock (Type · Talk · Breathe)
4. **Talk, voice off:** "I'll say hello first", the big Tap to start talking button, Write instead
5. **Talk, listening:** live caption, level bars, Mute / Write / End
6. **Talk, speaking:** orb speaking, caption streaming, "Speak anytime to interrupt"
7. **Talk, writing:** captions with pending dots, composer, tools (Style · Breathe · Transcript · End)
8. **Starters:** at the start of a conversation, quiet and dismissed on the first message
9. **Style sheet:** "What would help right now?", 4 options, with the acknowledgement line
10. **Slow reply:** after 8s it shows "Taking a little longer…", Stop waiting, and Switch to writing (voice only)
11. **Inline error:** "That didn't send. Your words are still here." with Try again
12. **Transcript sheet:** the full conversation, Copy, Close
13. **End confirm:** "End and make your card?" with End, or Keep talking
14. **Safety, elevated:** a Support options pill under the captions
15. **Safety, acute:** a care panel that opens on its own with Call / Text 988 and "I'm safe right now". It never covers the composer
16. **Get help sheet:** region picker, three lines with Call + Text, emergency number
17. **Breathe:** orb pacing, phase + count, pattern (Calm 4·6 / Box / 4·7·8), haptics, Done
18. **Reflection:** card, Does this feel right?, Save image / Read conversation / Delete, Your say (Edit, Sky), What I'll remember (Forget + Undo), guest prompt "Want to keep this?"
19. **Reflection, edit mode**
20. **Sky picker sheet**
21. **Delete confirm dialog:** reflection, memory item, or everything
22. **Your skies:** 30-day sky line, counts, recent list, empty state
23. **Your patterns:** constellation, topic sheet, empty state
24. **What I remember:** switch, In short, categories, Edit/Forget, Add, empty, off
25. **Settings:** account, conversations (memory, ambient sound, match my sky, haptics), privacy (export, delete everything), about
26. **Menu:** a sheet on phone, a right panel on desktop
27. **Sign in:** Google + magic link, plus the check-your-email state
28. **Privacy page**
29. **Share card:** 1080×1350 feed and 1080×1920 stories
